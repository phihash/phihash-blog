Docker

コンテナのメモリ上限を見張っている仕組みは？

cgroup。プロセスのまとまりごとにリソースを制限する Linux カーネルの仕組み。

コンテナがメモリ上限を超えると何が起きる？

カーネルの OOM キラーが、cgroup 内でメモリを多く使うプロセスを選んで SIGKILL (9) を送る。

終了コード 137 の意味は？

128 + 9 で、SIGKILL で終了したということ。OOM とは限らず、docker kill でも 137 になる。

137 が OOM かどうかの確かめ方は？

docker inspect の OOMKilled が true か見る。

アウトオブメモリとメモリリークは同じ？

違う。リークは OOM の原因の一つ。巨大なデータの読み込みや、上限設定が小さい場合も、リークなしで OOM になる。
